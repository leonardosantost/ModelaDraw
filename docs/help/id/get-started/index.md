# Memulai

Halaman-halaman ini memperkenalkan ModelaDraw: bagian-bagian jendela, cara
membuat, membuka, dan menyimpan gambar, cara bergerak di dalam gambar dan
membatalkan pekerjaan, serta tempat mencari bantuan selagi menggambar.

ModelaDraw berjalan di Windows, macOS, dan Linux, serta di peramban web tanpa
perlu memasang apa pun. Keduanya program yang sama; sedikit perbedaan versi
peramban dijelaskan di [Versi peramban](browser-version.md).
